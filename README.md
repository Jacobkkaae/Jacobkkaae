## Featured Projects

### [VIPER — Real-Time Video Inpainting on Edge Devices](https://github.com/Tdelasson/Video-inpainter-for-edge-devices)

Bachelor project focused on real-time video inpainting on an **NVIDIA Jetson Orin Nano**. Developed a novel lightweight U-Net architecture with ConvGRU temporal memory and gated depthwise-separable convolutions to reduce computational cost while maintaining video quality. The system is designed for privacy-aware processing of video directly on edge hardware.

*Developed as part of a team at Aalborg University.*

### [Spatio-Temporal Data Imputation for Road Networks — aSTEP, AAU](https://github.com/astep-aau/Attribute-Prediction)

Semester project on the bachelor developing a machine learning pipeline for imputing missing travel-time data in road networks. Combines **Graph Neural Networks (GAT and GraphSAGE)** to model spatial relationships with recurrent neural networks for temporal patterns. Includes model training, hyperparameter experiments, and evaluation of different approaches.

*Developed as part of a project at Aalborg University.*

### [Consilio — P4 Software Project](https://github.com/3xTremee/ConsilioFinal_P4)

Semester project on the bachelor involving the design and implementation of a novel domain-specific planning language and interpreter. Developed lexical analysis, parsing, AST construction, type checking, and a breadth-first search planner for generating valid plans.

*Developed as part of a team at Aalborg University.*
